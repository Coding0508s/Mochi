# GrapeSEED MOCHI 플랫폼 사용 설명서

## 1. 이 문서는 무엇인가요?

**GrapeSEED MOCHI**(이하 **이 플랫폼**)는 GrapeSEED 운영 업무를 한 곳에서 처리하는 사내 업무 시스템입니다.

이 설명서는 로그인한 직원이 일상적으로 화면을 어떻게 쓰는지, 권한에 따라 무엇이 달라지는지를 정리한 **사용자용 안내서**입니다.

**대상**

- CO / CS / Coach 등 현장·운영 직원
- Full Access(관리자) 및 GS Brochure 운영 담당자
- GS Brochure **외부** 신청·조회 사용자(별도 절 포함)

---

## 2. 빠른 시작 (처음 쓰는 분)

1. 회사에서 안내받은 **주소(URL)** 로 접속합니다.
2. **이메일·비밀번호**로 로그인합니다. (`is_active`가 꺼진 계정은 로그인되지 않습니다.)
3. 로그인 후 기본 화면은 **기관리스트**입니다.
4. 왼쪽 **사이드바**에서 업무 메뉴를 고릅니다.
5. 오른쪽 상단에서 **프로필**, **알림**, **로그아웃**을 사용합니다.
6. 상단 링크로 **Portal**, **eCount**, **Coaching** 등 외부 사이트로 이동할 수 있습니다.

| 하고 싶은 일 | 메뉴 위치 |
| --- | --- |
| 운영 중인 기관 찾기 | Teams → CO Team → **기관리스트** |
| 기관 담당자 연락처 | Teams → CO Team → **교직원 연락처보기** |
| 방문·지원 기록 남기기 | Teams → CO Team → **기관지원보고서** 또는 **지원보고서 작성** |
| 잠재 고객 등록 | Teams → CO Team → **잠재기관 등록하기** |
| 팀·개인 일정 | Teams → CO Team → **일정 관리** |
| 내 계정 정보 | 상단 **프로필** (이름 클릭) |

---

## 3. 플랫폼에서 할 수 있는 일

- 직원(People) 정보 조회
- 기관 정보·담당자(CO/TR/CS) 관리
- 교직원 연락처 등록·수정
- 기관 지원 보고서 작성·조회·계약서 첨부
- 잠재기관 등록·계약 전환
- 팀·개인 **일정** 캘린더
- Store 재고·판매 이력
- Salesforce 관련 파일 관리
- GS Brochure 신청·운영
- (관리자) 팀·공통코드·역할·직원 등록

## 4. 접속·로그인·계정

### 4.1 접속

- 로그인 전 **루트(`/`)** 에 접속하면 로그인 화면으로 이동합니다.
- 로그인 후 **루트** 또는 **대시보드**로 들어가면 **기관리스트**로 이동합니다.

### 4.2 상단 바

| 위치 | 기능 |
| --- | --- |
| 브랜드 | GrapeSEED MOCHI |
| OutLook / Portal / eCount / Coaching | 외부 링크(새 탭) |
| 종 모양 아이콘 | **수신 알림** (외부 연동·기관 관련 알림) |
| 이름 영역 | **프로필** 편집 화면 |
| 로그아웃 | 세션 종료 |

### 4.3 비밀번호를 잊었을 때

1. 로그인 화면에서 **비밀번호 찾기** 링크를 누릅니다.
2. 가입된 **이메일**을 입력하고 재설정 메일을 요청합니다.
3. 메일의 링크로 들어가 **새 비밀번호**를 설정합니다.
4. 새 비밀번호로 다시 로그인합니다.

> 신규 직원 등록 시에도 비밀번호 설정 안내 메일이 갈 수 있습니다. 메일이 오지 않으면 스팸함을 확인하거나 관리자에게 문의하세요.

### 4.4 프로필

- 경로: 상단 **프로필** → `/profile`
- **이름·전화번호** 등 일부 항목은 수정할 수 있습니다.
- **이메일은 프로필에서 변경할 수 없습니다.** 변경이 필요하면 관리자에게 요청하세요.
- 로그인한 상태에서 **비밀번호 변경**은 프로필(또는 계정 설정) 메뉴에서 할 수 있습니다.

### 4.5 수신 알림(종 아이콘)

- 외부 시스템·기관 연동과 관련된 **수신 알림**이 표시됩니다.
- 알림을 **읽음 처리**하거나 **전체 비우기**할 수 있습니다. 비우기는 **본인 화면**에만 적용되며, 다른 사용자 알림에는 영향을 주지 않습니다.

## 5. 권한 — 내 화면이 왜 다를까요?

권한에 따라 **메뉴 노출**, **수정 버튼**, **보이는 데이터 범위**가 달라집니다.

### 5.1 용어

| 용어 | 의미 |
| --- | --- |
| **일반 직원** | 로그인만 된 상태. 대부분 조회·일반 업무 가능 |
| **Full Access(관리자)** | `is_admin = true`. Setup·Store 품목 관리·People 편집 등. **사람 단위만** 지정 |
| **직책 권한 표** | Setup → **직책 권한** 메뉴. 직책별 기능 플래그 7개를 한곳에서 관리 |
| **기능 플래그(7개)** | Setup 조회·Setup 관리, Store 재고 수정, GS Brochure 관리, Coach 팀 KPI, 기관 전체 조회, 부관리자 — 직책 표에서 부여·동기화 |

> 직원 마스터의 직책(JOB)만으로는 관리자가 되지 **않습니다.** 관리자는 `is_admin` 플래그로 판별합니다.

**직책과 기능 권한**

- Setup **직책 권한** 표에서 직책(`job_title` 공통코드)마다 위 **7개 기능 플래그**를 켜거나 끕니다.
- 직원 `JOB`이 바뀌거나 표를 저장하면, 해당 직원의 로그인 계정(`users`)에 플래그가 **자동 동기화**됩니다.
- **People**에서는 **Full Access(`is_admin`)** 와 **계정 활성(`is_active`)** 만 개인별로 지정합니다. 위 7개 플래그는 People에서 수동으로 바꾸지 않습니다.

**운영(배포·초기 설정)**

1. DB 마이그레이션 적용
2. Setup → **직책 권한**에서 표를 채운 뒤 저장
3. 필요 시 `php artisan users:sync-permissions-from-job-titles` 를 **수동** 실행

> 표가 비어 있는 상태에서 위 전체 sync 명령을 실행하지 마세요. 비관리자 계정의 기능 플래그가 일괄 off 될 수 있습니다.

### 5.2 기능별 요약

| 기능 | 일반 | Full Access | GS Brochure 전용 |
| --- | :---: | :---: | :---: |
| 기관·연락처·지원·일정 등 업무 화면 | O | O | O (허용 범위) |
| GS Brochure 신청 목록(내부) | O | O | O |
| People 직원 본문·팀 생성/삭제 | X | O | X |
| People 부서 이동 | X | O | X |
| Setup(팀·공통코드·역할·직원 등록) | X | O | X |
| Store 품목 관리·재고 수정 | X² | O | X |
| GS Brochure 관리자 대시보드 | X | O | O |

² Full Access **또는** 직책 권한 표에서 「Store 재고 수정」이 켜진 경우 Store 재고 수정 가능.

### 5.3 데이터가 일부만 보일 때

- **CO 팀** 소속이면서 Full Access가 **아닌** 경우, **기관리스트** 등에서 **본인 담당(CO 이름)** 과 맞는 행만 보일 수 있습니다.
- **잠재기관** 화면(등록·목록)에서도 Full Access가 아니면, **본인이 등록한 건** 또는 **레거시 데이터 중 본인이 담당자로 매칭되는 건**만 보입니다. 필터 옵션·건수도 같은 범위로 제한됩니다.

### 5.4 팀별 사이드바 메뉴

소속에 따라 **Teams** 아래에 보이는 하위 메뉴가 다릅니다.

| 소속 | 보이는 팀 메뉴 |
| --- | --- |
| **CS 팀** | CS Team (기관·연락처·지원·일정) |
| **Coach 팀** | Coach Team (동일 공통 메뉴) |
| **CO 팀** | CO Team (잠재기관·Store·GS Brochure 등 CO 전용 메뉴 포함) |
| **관리자·기타** | CS Team + Coach Team + CO Team |

CO Team 전용 메뉴 예: 잠재기관, GS Brochure, Store, Salesforce 파일.

## 7. 기능별 사용 방법

### 7.1 People

직원 정보를 **조회**하는 화면입니다.

- 이름·이메일·부서 검색, 상태·부서 필터, 정렬
- **Full Access**만: 직원 본문 저장, 팀 생성/삭제, 부서 이동, 계정 필드·직원 등록 모달 등

### 7.2 기관리스트

운영 중인 기관을 검색·조회하고, 상세 모달에서 담당·유형 등을 수정합니다.

**검색·필터**: 기관명·코드, 기관 구분, 담당 배정 상태, 정렬

**상세에서 확인**: 기본 정보, CO/TR/CS, 고객 유형, GS 번호, 교사 수, 지원 이력·최근 지원일 등

**수정 가능(권한·화면에 따라)**: 고객 유형, GS 번호, CO/TR/CS

### 7.3 교직원 연락처보기

기관 담당 교직원 연락처를 조회·등록·수정·삭제합니다.

- 검색: 이름, 이메일, 기관명, 전화번호
- 재직 상태 필터
- 등록 항목: 이름, 전화, 이메일, 직급, 기관(SK 코드), 재직 상태, 수업 참여, 비고

### 7.4 기관지원보고서

기관 지원 이력 조회, 계약서 파일 업로드·다운로드·미리보기.

- 연도·담당 TR·기관·키워드 필터
- 계약서: 최대 20MB, `pdf`·이미지·Office 문서 등 허용 형식

### 7.5 지원보고서 작성

경로: `/supports/create`

- 일반 기관(SK 코드) 또는 **잠재기관** 선택
- 지원 일시·방식·참석자·공유 내용·완료 여부·첨부
- **파일 업로드**는 SK 코드가 있는 기관에만 가능

### 7.6 잠재기관

| 화면 | 용도 |
| --- | --- |
| **잠재기관 등록하기** | 신규 등록·상세·**계약완료** 처리 |
| **잠재기관 목록보기** | 등록된 잠재기관 목록·필터·요약 |

**필터 예**: 연도, 담당자, 유형, 지역, 소개경로, 계약가능성, 신규/종료

**계약완료** 시: 기관리스트에 반영. 코드가 없으면 `LEAD-{ID}` 형식이 될 수 있음.

**미계약 전환** 시: 기관리스트에서 숨김 처리.

> Full Access가 아니면 **본인 관련 잠재기관만** 목록·필터·건수에 표시됩니다.

### 7.7 일정 관리

경로: **일정 관리** (`/schedules`)

팀·개인 일정을 **캘린더** 또는 **리스트**로 봅니다.

#### 화면 조작

| 조작 | 설명 |
| --- | --- |
| 이전 달 / 이번 달 / 다음 달 | 월 이동 |
| **내 일정** | 본인이 등록한 일정만 |
| **팀 일정** | 본인 + 같은 부서(WORKDEPT) 동료의 **팀 공개** 일정 |
| 캘린더 / 리스트 | 보기 방식 전환 |
| 유형·상태 필터 | 미팅·업무·개인·기타 / 예정·완료·취소 |
| 날짜 칸 클릭 | 해당 날 **일정 목록** 모달 |
| 빈 날·「일정 추가」 | 새 일정 등록 |

#### 일정 등록·수정

| 항목 | 설명 |
| --- | --- |
| 제목 | 필수 |
| 설명·장소 | 선택 |
| 날짜·시작/종료 시간 | 종일 일정 가능. 종료는 시작보다 늦어야 함 |
| 유형 | 미팅 / 업무 / 개인 / 기타 |
| **공개 범위** | **비공개**: 본인만 / **팀 공개**: 같은 부서 팀 일정에 표시 |
| 상태 | 예정 / 완료 / 취소 |
| 반복 | 없음 / 매주 / 격주 / 매월 (최대 52·26·12회 생성) |

#### 권한·주의

- **본인 일정**: 등록·수정·삭제 가능
- **다른 사람 팀 공개 일정**: **보기만** 가능(수정 불가). 화면에 안내 문구가 표시됩니다.
- **부서(WORKDEPT)가 없는** 계정: 팀 일정에서 **본인 일정만** 보이고, 다른 사람 일정은 보이지 않습니다.
- **Full Access**는 팀 일정에서 **팀원별 필터**로 특정 사람 일정만 볼 수 있습니다.
- **반복 일정 삭제**: 「이 일정만」 또는 「이후 전체」 선택

### 7.8 Store 재고

- 상품코드·상품명 검색, 재고 목록, 최근 차감 상세
- **스토어사이트 재고 수정**(권한 필요): 음수 불가, **변경 사유 필수**, 수량이 같으면 저장 불가. 변경 이력은 앱 DB에 기록
- **품목 관리**: Full Access

상세: [Store 재고 품목 관리 가이드](store-inventory-sku-manager-guide.md)

### 7.9 Store판매내역

판매·차감 근거 확인용 조회 화면입니다.

### 7.10 Salesforce파일

기관별·미연결 파일 조회, 미리보기, 수정, 교체 업로드, 삭제.

### 7.11 GS Brochure

#### 외부 신청자

| 경로 | 용도 |
| --- | --- |
| `/co/gs-brochure/request` | 신청서 작성 |
| `/requestbrochure-list-v2` | 본인 신청 조회 |

**신청 순서**: 신청일 → 기관명 → 주소 → 전화 → **인증번호** → 브로셔·수량(10권 단위) → 신청

#### 내부 직원

- 신청 목록: `/co/gs-brochure/request?view=list` 또는 `/co/gs-brochure/requests`
- 로그인 사용자 조회·권한 범위 내 수정

#### 관리자 대시보드

- 경로: `/co/gs-brochure/admin/dashboard`
- 권한: Full Access 또는 `is_gs_brochure_admin`
- 재고·운송장·입출고·기관관리·설정 등

### 7.12 Setup (Full Access)

| 메뉴 | 기능 |
| --- | --- |
| 팀 관리 | 팀 CRUD (소속 직원 있으면 삭제 불가) |
| 공통코드 | 직책·고객유형·상태값 |
| 역할·권한 | 메뉴별 view/create/update/delete |
| 직원 등록 | 신규 직원·로그인 계정 생성 |

## 8. 자주 쓰는 업무 흐름

### 8.1 신규 계약 기관

1. **잠재기관 등록하기**에서 대상 확인
2. **계약완료** 처리
3. **기관리스트**에서 반영 확인
4. CO/TR/CS 보정
5. **교직원 연락처보기**에서 연락처 등록

### 8.2 기관 방문 후

1. **지원보고서 작성** 또는 **기관지원보고서**에서 등록
2. 필요 시 첨부·계약서 업로드
3. 목록에서 이력 확인

### 8.3 팀 일정 공유

1. **일정 관리** → 일정 추가
2. 공개 범위를 **팀 공개**로 설정
3. 팀원은 **팀 일정** 보기에서 확인 (같은 부서·직원 연결 계정 기준)

### 8.4 Store 재고

1. **Store 재고**에서 품목·차감 확인
2. 권한 있으면 스토어사이트 재고 수정(사유 입력)
3. 품목 추가·비활성은 Full Access → **품목 관리**

### 8.5 GS Brochure

1. 외부 신청 → 2. 내부 목록 확인 → 3. 관리자 대시보드에서 재고·운송장 처리

## 9. 문제 해결 (FAQ)

| 증상 | 확인할 것 |
| --- | --- |
| 로그인이 안 됨 | 이메일·비밀번호, 계정 **활성(is_active)** 여부 |
| 메뉴가 안 보임 | Full Access·팀 소속(CO/CS/Coach)·GS 관리자 플래그 |
| 수정 버튼이 없음 | 해당 화면 권한, CO 담당 스코프, 타인 일정(보기 전용) |
| 기관이 목록에 없음 | CO 담당 필터, 잠재기관 미계약·스코프 |
| 잠재기관이 적게 보임 | Full Access 아님 → 본인 등록·담당 매칭만 표시 |
| 팀 일정에 동료가 안 보임 | 상대 일정이 **팀 공개**인지, 같은 **부서**·직원 연결 여부 |
| 프로필 이메일 저장 실패 | 이메일은 변경 불가 → 관리자 요청 |
| Store 재고 저장 실패 | 사유 미입력, 수량 동일, 권한 없음 |

## 10. 운영 시 주의

- 권한 없는 기능은 버튼·메뉴가 숨겨지거나 접근이 차단됩니다.
- **준비 중** 메뉴는 실제로 동작하지 않을 수 있습니다.
- 외부 링크(Portal, eCount 등)는 이 플랫폼과 별도 로그인이 필요할 수 있습니다.
