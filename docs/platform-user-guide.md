## 1. 이 플랫폼은 무엇인가요?

**GrapeSEED MOCHI**는 GrapeSEED 운영 업무를 한곳에서 처리하는 **사내 업무 시스템**입니다.

한 줄로 말하면:

- **기관·교사·연락처**를 찾고
- **방문·지원·이슈**를 남기고
- **잠재 고객·계약**, **재고·반품·브로셔**, **일정·공용품**을 처리합니다.

로그인 후 기본 화면은 **기관리스트**입니다.

## 2. 빠른 시작 (처음 쓰는 분)

1. 회사에서 안내받은 **주소(URL)** 로 접속합니다.
2. **이메일·비밀번호**로 로그인합니다. (비활성 계정은 로그인되지 않습니다.)
3. 왼쪽 **사이드바**에서 업무 메뉴를 고릅니다.
4. 오른쪽 상단에서 **프로필**, **알림**, **로그아웃**을 사용합니다.
5. 상단 링크로 **Portal**, **eCount**, **Coaching** 등 외부 사이트로 갈 수 있습니다. (별도 로그인이 필요할 수 있습니다.)

| 하고 싶은 일 | 메뉴 위치 |
| --- | --- |
| 운영 중인 기관 찾기 | Teams → 소속 팀 → **기관리스트** |
| 기관 담당자 연락처 | Teams → 소속 팀 → **교직원 연락처보기** |
| 방문·지원 기록 | Teams → 소속 팀 → **기관지원보고서** (Coach는 **교사 및 기관 지원**) |
| 교사 지원·수업 이력 | Teams → Coach Team → **교사 지원 현황** |
| CS 기관 이슈 | Teams → CS Team → **기관 이슈** |
| 잠재 고객 등록 | Teams → CO Team → **잠재기관 등록하기** |
| 재고·판매 | Teams → CO Team 또는 Logistics Team |
| 반품 | Teams → CS Team 또는 Logistics Team → **반품 현황** |
| 일정·공용품·차량 | 사이드바 **일정 관리** (관리자 메뉴) |
| 내 계정 | 상단 **이름** → 프로필 |

## 3. 화면 구성

화면은 크게 세 부분입니다.

| 위치 | 하는 일 |
| --- | --- |
| **위쪽 바** | 브랜드명, 외부 사이트 링크, 알림(종), 이름(프로필), 로그아웃 |
| **왼쪽 사이드바** | People, 일정 관리, Teams, Setup 등 업무 메뉴 |
| **가운데 본문** | 선택한 화면의 목록·검색·상세 |

모바일에서는 왼쪽 위 **메뉴 버튼**으로 사이드바를 엽니다.

**다른 팀 메뉴**를 열면 노란 안내가 뜰 수 있습니다.

> 타 팀 메뉴에서는 조회만 가능합니다.

내 소속 팀이 아닌 메뉴에서는 **보기만** 되고, 저장·삭제 버튼이 없거나 막힐 수 있습니다.

## 4. 접속·로그인·계정

### 4.1 접속

- 로그인 전 첫 화면(`/`)은 **로그인**으로 이동합니다.
- 로그인 후 첫 화면 또는 **대시보드**는 **기관리스트**로 이동합니다.

### 4.2 비밀번호를 잊었을 때

1. 로그인 화면에서 **비밀번호 찾기**를 누릅니다.
2. 가입된 **이메일**을 넣고 재설정 메일을 요청합니다.
3. 메일의 링크로 들어가 **새 비밀번호**를 설정합니다.

메일이 없으면 스팸함을 확인하거나 관리자에게 문의하세요.  
신규 직원 등록 시에도 비밀번호 설정 안내 메일이 갈 수 있습니다.

### 4.3 첫 로그인 후 비밀번호 변경

관리자가 계정을 만들어 주면, **반드시 비밀번호를 바꾸라**는 화면이 나올 수 있습니다.  
안내대로 새 비밀번호를 저장한 뒤 다시 사용합니다.

### 4.4 프로필

- 경로: 상단 **이름** → `/profile`
- **이름·전화번호** 등 일부 항목은 본인이 수정할 수 있습니다.
- **이메일은 프로필에서 바꿀 수 없습니다.** 변경이 필요하면 관리자에게 요청하세요.
- 로그인한 상태에서 **비밀번호 변경**도 프로필에서 할 수 있습니다.

### 4.5 수신 알림(종 아이콘)

- 외부 시스템·기관 연동과 관련된 **수신 알림**이 표시됩니다.
- **읽음 처리** 또는 **전체 비우기**는 **본인 화면**에만 적용됩니다.

## 5. 권한과 보이는 메뉴

권한에 따라 **메뉴**, **수정 버튼**, **보이는 데이터 범위**가 달라집니다.  
직책(JOB)만으로는 관리자가 되지 않습니다.

### 5.1 용어 (쉽게)

| 용어 | 쉽게 말하면 |
| --- | --- |
| **일반 직원** | 로그인된 상태. 대부분 조회·자기 팀 업무 |
| **Full Access(관리자)** | 플랫폼 전반 조회·수정, Setup, 일정 관리 메뉴, 품목 관리 등 |
| **부관리자** | 관리자만큼 넓게 **조회**. 삭제 같은 강한 작업은 관리자만 |
| **GS Brochure 관리자** | 브로셔 재고·운송장 등 운영 대시보드 |
| **스토어 재고 수정** | People에서 켜 줄 수 있는 권한. 관리자가 아니어도 재고 수량 수정 가능 |
| **Coach 팀장** | Coach Team의 **지원방법·횟수**, **팀 지원 KPI** 메뉴 |
| **기관 전체 조회** | 기관리스트에서 담당 필터 없이 전체 기관을 보는 권한 |

### 5.2 데이터가 일부만 보일 때

- **CO 팀**이면서 관리자·전체조회 권한이 없으면, 기관리스트에서 **본인 담당(CO 이름)** 과 맞는 행만 보일 수 있습니다.
- **잠재기관**은 관리자가 아니면 **본인이 등록한 건** 또는 **본인이 담당자로 매칭되는 건**만 보입니다. 필터·건수도 같은 범위입니다.
- **Coach** 교사 화면은 담당 코치 범위에 맞춰 보일 수 있습니다.

### 5.3 사이드바에 팀 메뉴가 여러 개 보이는 이유

로그인한 직원에게는 Teams 아래에 **CS / Coach / CO / Logistics**가 함께 보일 수 있습니다.  
**자기 팀 메뉴에서 일하는 것이 기본**입니다. 다른 팀 메뉴는 주로 **조회**입니다.

| 소속(대략) | 주로 쓰는 메뉴 |
| --- | --- |
| **CS** | CS Team (기관, 연락처, 지원, **기관 이슈**, **반품**, 브로셔 신청) |
| **Coach** | Coach Team (교사 지원, 기관·연락처, 퇴직교사 등) |
| **CO** | CO Team (잠재기관, GS Brochure, Store, Salesforce 파일) |
| **Logistics** | Logistics Team (재고, 판매, 반품, 브로셔 재고·운송장) |
| **관리자 / Administration** | 위 팀 + **Admin**(기관리스트, 연락처, 퇴직교사) + **Setup** + **일정 관리** |

## 7. 기능별 사용 방법

### 7.1 People

직원 정보를 **조회**하는 화면입니다.

- 이름·이메일·부서 검색, 상태·부서 필터, 정렬
- **Full Access**만: 직원 본문 저장, 팀 생성/삭제, 부서 이동, 계정 필드, 직원 등록 모달 등

### 7.2 기관리스트

운영 중인 기관을 검색·조회하고, 상세에서 담당·유형 등을 확인·수정합니다.

**검색·필터**: 기본은 **운영 기관**(해당 연도에 해지된 기관은 목록에 남고, 기관명 옆에 `26년 해지`처럼 연도가 작게 표시됩니다). 기관명·코드, 기관 구분, 담당 배정 상태, 정렬. 목록은 페이지 나누기 없이 표 안에서 스크롤합니다.

**상세에서 확인**: 기본 정보, CO/TR/CS, 고객 유형, GS 번호, 교사 수, 지원 이력·최근 지원일 등

**수정 가능(권한·화면에 따라)**: 고객 유형, GS 번호, CO/TR/CS

신규 기관 직접 등록(`/institutions/create`)은 **기능이 꺼져 있으면** 목록으로 돌아가며, 안내에 “신규 기관 등록이 비활성화”라고 나옵니다. 보통은 **잠재기관 → 계약완료**로 기관리스트에 올립니다.

### 7.3 교직원 연락처보기

기관 담당 교직원 연락처를 조회·등록·수정·삭제합니다.

- 검색: 이름, 이메일, 기관명, 전화번호
- 재직 상태 필터
- 등록 항목: 이름, 전화, 이메일, 직급, 기관(SK 코드), 재직 상태, 수업 참여, 비고
- **내 담당만** 같은 토글이 있으면, 본인에게 배정된 연락처만 볼 수 있습니다.

### 7.4 기관지원보고서 / 교사 및 기관 지원

기관(또는 교사) 지원 이력을 조회하고, 계약서 파일을 올리거나 받습니다.

- 연도·담당 TR·기관·키워드 필터
- 목록에서 **지원보고서 작성**으로 새 기록을 남깁니다.
- 계약서: 최대 20MB, `pdf`·이미지·Office 문서 등 허용 형식

Coach Team에서는 같은 화면이 **교사 및 기관 지원**으로 보입니다.

### 7.5 지원보고서 작성

경로: `/supports/create`

- 일반 기관(SK 코드) 또는 **잠재기관** 선택
- 지원 일시·방식·참석자·공유 내용·완료 여부·첨부
- **파일 업로드**는 SK 코드가 있는 기관에만 가능합니다.
- CS **기관 이슈 작성**은 `report_mode=issue`로 이슈 전용 양식이 열립니다.

### 7.6 기관 이슈 (CS)

경로: Teams → CS Team → **기관 이슈** (`/institution-issues`)

같은 기관+교사는 **한 줄**로 묶이고, 줄을 누르면 이슈 목록 모달이 열립니다.

| 조작 | 설명 |
| --- | --- |
| 연도·검색 | 기관명, SK코드, 교사명, 이슈 내용 |
| 긴급 이슈만 보기 | 긴급으로 표시된 건만 |
| 기관 이슈 작성 | 새 이슈 작성 화면 |
| 행 클릭 | 그룹 상세. 완료 처리·수정·삭제(권한 있을 때) |

### 7.7 잠재기관

| 화면 | 용도 |
| --- | --- |
| **잠재기관 등록하기** | 신규 등록·상세·**계약완료** |
| **잠재기관 목록보기** | 목록·필터·요약 |

**필터 예**: 연도, 담당자, 유형, 지역, 소개경로, 계약가능성, 신규/종료

**계약완료**: 기관리스트에 반영됩니다. 코드가 없으면 `LEAD-{ID}` 형식이 될 수 있습니다.  
**해지 후 재계약**은 **기존 SK 코드**를 그대로 쓰는 것이 원칙입니다. 자세한 규칙은 [해지·재계약 문서](institution-termination-recontract.md)를 보세요.

**미계약 전환**: 기관리스트에서 숨김 처리됩니다.

> 관리자가 아니면 **본인 관련 잠재기관만** 목록·필터·건수에 표시됩니다.

### 7.8 교사 지원 현황 (Coach)

경로: Teams → Coach Team → **교사 지원 현황** (`/coach/teacher-support`)

교사별 지원·수업 이력을 보고, 방문·오픈클래스 등 **지원 보고서**를 남깁니다.

- 연도·회차·월·담당 코치·검색. **연도는 3월~다음 해 2월이 1주기**입니다. (예: 2026년 = 2026년 3월~2027년 2월)
- 직급(기본: 교사), 고용 형태(정규/파트 등) 필터
- 교사 상세에서 프로필 수정, 지원 이력, **퇴직** 처리(권한·안내에 따름)

### 7.9 퇴직교사 리스트

경로: Coach Team 또는 Admin → **퇴직교사 리스트**

- 연도, 이름 검색, 추천 여부, 퇴직/복직 상태
- 상세 모달, **복직** 처리(기관 선택 등)
- 목록 엑셀 내려받기(화면에 버튼이 있을 때)

### 7.10 지원방법·횟수 / 팀 지원 KPI

Coach **팀장** 또는 관리자만 사이드바에 보입니다.

- **지원방법·횟수** (`/coach/institution-coverage`): 기관별 지원 방법·횟수
- **팀 지원 KPI** (`/coach/team-kpi`): 팀 지원 실적 요약

권한이 없으면 주소로 들어가도 막힙니다.

### 7.11 일정 캘린더

경로: **일정 관리** → 일정 캘린더 (`/schedules`)

팀·개인 일정을 **캘린더** 또는 **리스트**로 봅니다.

| 조작 | 설명 |
| --- | --- |
| 이전 달 / 이번 달 / 다음 달 | 월 이동 |
| **내 일정** | 본인이 등록한 일정만 |
| **팀 일정** | 본인 + 같은 부서(WORKDEPT) 동료의 **팀 공개** 일정 |
| 캘린더 / 리스트 | 보기 방식 |
| 유형·상태 | 미팅·업무·개인·기타 / 예정·완료·취소 |
| 날짜 칸 | 그날 일정 목록 |
| 빈 날·일정 추가 | 새 일정 (또는 공용품 예약으로 이어질 수 있음) |

| 항목 | 설명 |
| --- | --- |
| 제목 | 필수 |
| 설명·장소 | 선택 |
| 날짜·시작/종료 | 종일 가능. 종료는 시작보다 늦어야 함 |
| 공개 범위 | **비공개**: 본인만 / **팀 공개**: 같은 부서 팀 일정에 표시 |
| 반복 | 없음 / 매주 / 격주 / 매월 (횟수 상한 있음) |

- **본인 일정**: 등록·수정·삭제 가능
- **다른 사람 팀 공개 일정**: 보기만
- **부서(WORKDEPT)가 없는** 계정: 팀 일정에서 **본인 일정만**
- **반복 삭제**: 「이 일정만」 또는 「이후 전체」

### 7.12 공용품 관리

경로: 일정 관리 → **공용품 관리**

노트북·차량 등 **공용품 예약**을 등록·조회합니다.

- 기간·검색, 사용자/관리 탭
- 사용 날짜·시간(또는 종일), 품목, 목적
- 차량이면 주행거리·도착지 등 추가 항목
- 저장 후 **지원보고서 작성**을 이어서 하라는 안내가 나올 수 있습니다.
- 관리자만 품목 초기화 등 강한 작업을 할 수 있습니다.

### 7.13 차량별 사용 내역

공용품 중 **차량** 사용 이력을 모아 보는 화면입니다. 날짜·차량별로 누가 썼는지 확인합니다.

### 7.14 Store 재고

- 상품코드·상품명 검색, 재고 목록, 최근 차감
- **스토어사이트 재고 수정**(권한 필요): 음수 불가, **변경 사유 필수**, 수량이 같으면 저장 불가
- **품목 관리**: Full Access 또는 스토어 재고 수정 권한 → `/store/inventory/skus`

상세: [Store 재고 품목 관리 가이드](store-inventory-sku-manager-guide.md)

### 7.15 Store 판매내역

판매·차감 근거를 확인하는 조회 화면입니다.

### 7.16 반품 현황

경로: CS Team 또는 Logistics Team → **반품 현황** (`/store/returns`)

- 목록에서 검색·상태 필터, 상세 보기
- **등록**으로 반품일, 기관, 품목·수량·상태, 운임 등을 입력합니다.
- CS 메뉴와 Logistics 메뉴는 입력 항목이 조금 다를 수 있습니다. (CS는 CS팀 필드 등)
- **반품 등록 품목**(`/store/returns/products`)은 관리자가 선택지에 나올 품목을 관리합니다.

### 7.17 Salesforce파일

기관별·미연결 파일을 조회하고, 미리보기·수정·교체 업로드·삭제합니다.

### 7.18 GS Brochure

#### 외부 신청자 (로그인 없이)

| 경로 | 용도 |
| --- | --- |
| `/co/gs-brochure/request` | 신청서 작성 |
| `/requestbrochure-list-v2` | 본인 신청 조회 (기관명·전화) |

**신청 순서**: 신청일 → 기관명 → 주소 → 전화 → **인증번호** → 브로셔·수량(10권 단위) → 신청

#### 내부 직원

- CS: **브로셔 신청**
- CO: **GS Brochure** (신청·목록·권한에 따라 관리자 화면)
- 직원 목록: `/co/gs-brochure/request?view=list` 또는 `/co/gs-brochure/requests`

#### 관리자 대시보드

- 경로: `/co/gs-brochure/admin/dashboard`
- 권한: Full Access 또는 GS Brochure 관리자
- 재고·운송장·입출고·기관관리·설정
- Logistics 메뉴의 **GS Brochure**, **운송장 입력**도 이 대시보드의 해당 섹션입니다.

권한 세부: [GS Brochure 권한 정책](gs-brochure-permission-policy.md)

### 7.19 Setup

| 메뉴 | 기능 |
| --- | --- |
| SetUp 홈 | 팀 관리로 이동. 일부 카드는 **준비중** |
| 팀 관리 | 부서·팀 코드 및 소속 인원 (소속 직원이 있으면 삭제 불가) |

직원 등록·공통코드 등 일부 화면은 주소로 남아 있을 수 있으나, **사이드바에 없으면 일상적으로 쓰지 않습니다.** 계정 발급은 관리자(People 등)에게 요청하세요.

## 8. 자주 쓰는 업무 흐름

### 8.1 신규 계약 기관

1. **잠재기관 등록하기**에서 대상 확인·등록
2. **계약완료** 처리 (재계약이면 **기존 SK** 사용)
3. **기관리스트**에서 반영 확인
4. CO/TR/CS 보정
5. **교직원 연락처보기**에서 연락처 등록

### 8.2 기관 방문 후 (CO / CS)

1. **기관지원보고서**에서 **지원보고서 작성**
2. 필요 시 첨부·계약서 업로드
3. 목록에서 이력 확인

### 8.3 교사 방문 후 (Coach)

1. **교사 지원 현황**에서 교사 검색
2. 해당 교사에 지원 유형에 맞는 보고서 작성
3. 필요하면 **교사 및 기관 지원** 목록에서 이력 확인

### 8.4 CS 기관 이슈

1. **기관 이슈** → **기관 이슈 작성**
2. 기관·교사·내용·긴급 여부 입력
3. 목록에서 그룹을 열어 진행·완료 처리

### 8.5 반품

1. **반품 현황**에서 등록
2. 기관·품목·수량 확인
3. Logistics에서 재고·운송과 맞춰 처리

### 8.6 팀 일정·공용품 (관리자)

1. **일정 관리** → 일정 캘린더 또는 공용품 관리
2. 일정은 공개 범위를 **팀 공개**로 두면 같은 부서가 볼 수 있습니다.
3. 차량·공용품은 예약 후 사용 내역에서 확인합니다.

### 8.7 Store 재고

1. **Store 재고**에서 품목·차감 확인
2. 권한 있으면 수량 수정(**사유 필수**)
3. 품목 추가·비활성은 **품목 관리**

### 8.8 GS Brochure

1. 외부 또는 내부에서 **신청**
2. 직원이 목록에서 확인
3. 관리자·Logistics가 재고·운송장 처리

## 9. 문제 해결 (FAQ)

| 증상 | 확인할 것 |
| --- | --- |
| 로그인이 안 됨 | 이메일·비밀번호, 계정이 **활성**인지 |
| 메뉴가 회색이거나 없음 | 관리자·Setup·Coach 팀장·GS 관리자 권한 |
| 수정 버튼이 없음 | 해당 화면 권한, CO 담당 범위, **타 팀 조회 전용**, 타인 일정 |
| 기관이 목록에 없음 | CO 담당 필터, 잠재기관 미계약, 해지·숨김 |
| 잠재기관이 적게 보임 | 관리자가 아니면 본인 등록·담당만 |
| 팀 일정에 동료가 안 보임 | 상대 일정이 **팀 공개**인지, 같은 **부서**인지. 메뉴 자체가 관리자 전용일 수 있음 |
| 프로필 이메일 저장 실패 | 이메일은 변경 불가 → 관리자 요청 |
| Store 재고 저장 실패 | 사유 미입력, 수량 동일, 권한 없음 |
| 브로셔 대시보드가 안 열림 | GS Brochure 관리자 또는 Full Access 필요 |
| 화면이 안 바뀜 | `npm run dev` / `composer run dev` 가 필요할 수 있음(개발 환경) |

## 10. 운영 시 주의

- 권한 없는 기능은 버튼·메뉴가 숨겨지거나 접근이 차단됩니다.
- **준비 중** 메뉴는 실제로 동작하지 않을 수 있습니다.
- 외부 링크(Portal, eCount 등)는 이 플랫폼과 **별도 로그인**이 필요할 수 있습니다.
- 해지 기관을 다시 계약할 때는 **새 SK를 만들지 말고 기존 SK**를 사용합니다.
- 중요한 삭제(기관 이슈, 파일, 재고 품목 등)는 되돌리기 어려우니, 안내 문구를 읽고 진행하세요.
