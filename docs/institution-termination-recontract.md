# 해지 후 재계약 운영 규칙

## 원칙

- 같은 기관은 해지 후 다시 계약해도 기존 `SKcode`를 그대로 사용한다.
- `S_AccountName`, `S_Account_Information` 행은 삭제하지 않는다.
- 해지 상태는 별도 테이블로 옮기지 않고 `S_Account_Information.Customer_Type`에 `해지`가 포함되어 있는지로 판단한다.

## 재계약 처리

잠재기관에서 계약 완료 처리 시 기존 기관의 `SKcode`를 입력하면, 기존 마스터 행을 재사용한다.

이때 시스템은 다음을 자동으로 처리한다.

- `S_AccountName`의 기존 기관명, 원장명, 전화번호, 주소, 구분, 가능성 값은 비어 있지 않으면 유지한다.
- `S_Account_Information`의 기존 기관명과 주소도 비어 있지 않으면 유지한다.
- `Customer_Type`에 들어 있는 `해지` 토큰은 제거한다.
- `institution_visibility_overrides`에 숨김 행이 있으면 삭제해 목록에 다시 노출한다.

## 운영 시 주의점

- 재계약 기관에 새 SK를 만들지 말고 기존 SK를 사용한다.
- 해지 기관을 재계약 처리할 때는 잠재기관의 `AccountCode`에 기존 SK가 들어가 있어야 한다.
- `Customer_Type`에는 가능하면 `해지`를 독립된 단어로 넣는다. 예: `해지`, `VIP 해지`.
- `해지예정`처럼 `해지`가 다른 단어에 붙어 있는 값은 자동 제거 대상이 아니다.
